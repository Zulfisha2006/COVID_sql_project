# 🌍 COVID-19 Data Exploration Using SQL

A SQL-based data exploration project analyzing global COVID-19 cases, deaths, and vaccination trends using MySQL. This project demonstrates real-world data analysis techniques commonly used by Data Analysts.

---

## 📌 Project Overview

The objective of this project is to explore COVID-19 data and extract meaningful insights using SQL. It covers data aggregation, joins, window functions, Common Table Expressions (CTEs), temporary tables, and views to answer business-oriented analytical questions.

---

## 🛠️ Tech Stack

- **Database:** MySQL
- **Tool:** MySQL Workbench
- **Language:** SQL
- **Version Control:** Git & GitHub

---

## 📂 Dataset

The project uses two datasets:

- **CovidDeaths**
- **CovidVaccinations**

These datasets include country-wise information on:

- Population
- Total Cases
- Total Deaths
- New Cases
- New Deaths
- Vaccinations
- Reporting Date

---

## 📊 Key Analysis Performed

- Total Cases vs Total Deaths
